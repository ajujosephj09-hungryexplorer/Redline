### Priority Issues

**[P0] AnalysisView has no navigation structure for results**
Single flat scroll with 6 sections; no anchors, dividers, or section nav. Jordan has no guided path through the most consequential moment in the flow.
Fix: Add visible section separation (horizontal dividers, meaningful vertical spacing). Better: sticky section navigation for long results. Suggested: /impeccable layout

**[P1] No "start over" affordance after analysis begins**
No way to upload a different document without manual navigation away. A user who uploads the wrong file is stuck.
Fix: "Analyze a different contract" link in AnalysisView header; back/reset on /analyze.
Suggested: /impeccable harden

**[P1] Upload form duplicated verbatim across two routes**
/analyze/page.tsx InlineUploadForm is nearly identical to /upload/page.tsx — already diverged on one detail. Extract shared UploadForm component.
Suggested: /impeccable harden

**[P2] Counter-offer copy button is visually recessive for the most important action**
text-xs text-slate-500 is the quietest treatment for the product's main delivery action. Upgrade to small navy-bordered pill or icon+text button.
Suggested: /impeccable clarify

**[P2] GapCard vs FindingRow visual distinction underdeveloped**
Dashed border alone is insufficient. "Missing" amber text looks like a severity label. Give gaps distinct visual treatment.
Suggested: /impeccable clarify

**[P3] Rules page has no feedback loop to results**
No usage history — which rules fire frequently, which never trigger. Tuning rules is blind.
